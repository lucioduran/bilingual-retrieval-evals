# Security

This research CLI reads trusted local files. It is not an upload service and does not apply memory limits to arbitrary datasets. Model loading disables remote code and uses safetensors, but this is not a comprehensive dependency audit. Do not place credentials or personal data in public fixtures or reports.

Report a suspected vulnerability privately using the repository's GitHub security reporting channel if enabled. Otherwise contact the maintainer through the public profile without posting exploit details or secrets in an issue.
